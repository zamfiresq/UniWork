# Baze de Date

### Notare

	
- **Nota finala = (Nlab + Nexam) / 2, Nlab = 1 pct of + Nota test_laborator + bonus_lab (max. 1 pct.)** si
**Neaxm = 1 pct oficiu + N1 + N2 + activitate_curs (max. 2 pct. din teme si prezenta)**


- **N1 = max. 4 pct**, obtinute din rezolvarea cerintelor 1-13 ale proiectului, indiferent de complexitate
- **N2 = max. 3 pct**, obtinute din standardele de complexitate si raspunsurile din cadrul examinarii din sesiune

- **Standardul pentru nota 5 (nota test_laborator + 1 pct oficiu >= 5) si (1 pct oficiu + N1  = 5)**
    - Daca s-a indeplinit standardul pentru nota 5: se vor rezolva suplimentar punctele 14-17 din cerintele proiectului,
se pot obtine: bonus_lab, activitate_curs, N2
- **Daca nu s-a indeplinit standardul pentru nota 5 -> restanta**
