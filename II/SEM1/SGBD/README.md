# Sisteme de Gestiune a Bazelor de Date (DBMS)

### Notare
**N1 + N2 + N3 + N4**, unde

- **N1** = punctaj teme laborator (max 1 pct)
- **N2** = punctaj proiect (3 pct + 1 pct oficiu)
- **N3** = punctaj examinare din sesiune (max 3 pct)
- **N4** = punctaj activitate curs (max 2 pct)
- **N1 + N2 >= 5**  


**!** Promovarea **NU** e garantata daca N1 + N2 >= 5  
**!** N4 se aplica doar daca N1 + N2 + N3 = 8
